# Stabilize After Broad Prerelease Validation

The library will remain an explicitly non-adoptable `0.x` prerelease while its broad conventional
catalog, Markdown editor, chart family, and four integration slices challenge the public
foundation. Stable `1.0` and the default package tag require explicit acceptance after the full
behavioral, accessibility, visual, type, package, performance, browser, SSR, hydration, and bundle
isolation gates pass; normal semantic compatibility begins only then.
