# Own an Accessible Chart Family

The stable catalog will own a typed, responsive, SSR-safe chart family spanning common Cartesian,
radial, statistical, heatmap, and compact charts, including radar charts, with narrow named APIs
for ordinary use and a bounded advanced composition layer. The renderer remains private, chart
contracts govern appropriate use, and keyboard interaction, structured data alternatives,
non-color meaning, semantic states, and reduced motion are part of the component behavior rather
than application-specific afterthoughts.
