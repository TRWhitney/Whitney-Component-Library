# Publish Canonical Component Contracts

Every public export will have one canonical component contract from which human documentation, a
machine-readable manifest, and a compact agent index are derived. Narrow TypeScript APIs enforce
structural constraints while contracts communicate semantic selection; repository checks remain
deterministic and cover contract integrity, generated artifacts, examples, types, and component
behavior. Whitney authorized a small comparative agent-output evaluation for the
[agent consumption strategy pass](../../.work/agent-consumption-strategy/status.md). This limited
exception does not establish an ongoing evaluation suite, release gate, or prescribed consumer
workflow.
