# Responsive guidance experiment protocol

This is a historical study design, not an instruction to run another experiment. Results are
in the [study report](agent-guidance-layout.md).

## Design

Nine fresh directory attempts, three each with React/CSS, bundled guidance/pointers and that
package plus Table/Tabs supplements. Rotate native/control/layout, control/layout/native,
layout/native/control. Neutral names/briefs contain no guidance hints.

## Boundaries and checks

Only Table/Tabs usage changes. Preserve original behavior, examples, exact props and full
references; match runtime/declarations/metadata/index. Demonstrate ordinary application wrappers
using inventory content rather than the evaluated people directory. No internal-selector
guarantees. Preflight compiling examples, bounded 390px/1280px layout and installed parity,
then freeze. Fresh matching model/effort authors edit app/CSS and run matching builds.

## Measures and decision

Independently run 48 assertions per app across both widths, 432 primary assertions. Retain
initial failures and all targeted repair costs; distinguish transport failures from app defects.
Measure actual supplement content, subsequent runtime/CSS inspection and every matched pair.
Stop after nine attempts. One task and two simultaneous page changes cannot establish general
savings, isolate helpful wording or prove read motives.

Provider total counts input plus output, including cached input and reasoning once. Uncached
input plus output is a diagnostic, not a price. Reference/source estimates are separate from
provider accounting and cannot be subtracted to attribute savings. Include author reads,
failures, checks and repairs; exclude coordinator preparation, evaluation and analysis.
Inherited instruction costs remain in author totals. Study inputs were frozen before
authoring; raw captures are no longer retained.

Raw captures and one-off study tooling were removed. Exact historical replay is unavailable.
See the [evidence retention policy](agent-evidence-retention.md).
