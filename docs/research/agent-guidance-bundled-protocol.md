# Bundled guidance experiment protocol

This is a historical study design, not an instruction to run another experiment. Results are
in the [study report](agent-guidance-bundled.md).

## Design

Twenty-four fresh attempts: profile dialog, validated form and searchable/sortable directory;
React/CSS, current package, static usage/separate props and bundled usage/props/example pages;
two repetitions each. Rotate condition order. Static/Bundled share index, metadata, runtime,
declarations and full references; only 85 usage bodies differ.

## Boundaries and checks

Eight shared pages have reviewed short behavior/examples; remaining pages derive canonical
usage/access facts. Validate all props/fallbacks and eight compiling examples before freezing.
Neutral briefs name no docs or required components. Matching fresh model/effort authors edit
app/CSS and run type/build, with no browser self-checks or other-fixture inspection. Stop after
24 attempts and at most one objective repair per app.

## Measures and decision

Independently check at 390px/1280px: overlay/directory 48 assertions per app, form 40, totaling
1,088 primary assertions. Freeze acceptance; correct evaluator tooling consistently and
distinguish partial checks from app failures. Measure returned page content, follow-up/full/
implementation reads and failed operations. Compare task totals and both repetitions, rather
than selecting page readers after assignment. Small samples give descriptive evidence only.

Provider total counts input plus output, including cached input and reasoning once. Uncached
input plus output is a diagnostic, not a price. Reference/source estimates are separate from
provider accounting and cannot be subtracted to attribute savings. Include author reads,
failures, checks and repairs; exclude coordinator preparation, evaluation and analysis.
Inherited instruction costs remain in author totals. Study inputs were frozen before
authoring; raw captures are no longer retained.

Raw captures and one-off study tooling were removed. Exact historical replay is unavailable.
See the [evidence retention policy](agent-evidence-retention.md).
