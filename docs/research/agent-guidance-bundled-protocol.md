# Bundled static guidance comparison

Frozen before authoring. Test whether combining exact props, one minimal example, and key
behavior on a component page reduces follow-up reading and completed authoring tokens.

Run three tasks, two repetitions each, under four conditions: React/CSS, current installed
package, existing compact static references, and revised bundled static pages. Stop after
24 fresh attempts and at most one objective repair per attempt. Keep every attempt and failure.
No production changes, lookup command changes, publication, or commits.

Tasks cover an overlay editor, validated form, and searchable sortable directory with peer
tabs. Every condition uses the same task behavior, scaffold, local dependencies, inherited model,
effort, and evaluation. Explain non-repository fixture authorization upfront. Prompts contain
no guidance paths, mechanism hints, variant names, required library components, or example apps.
Agents may inspect their installed dependencies but cannot inspect other trials or source repos.
They edit only app.tsx and styles.css and run the same TypeScript/build check. No author browser
self-checks or added tests. Use fresh agents without parent-history forks. Rotate condition order
and retain actual launch order, context/cache limitations, and administrative interruptions.

Package runtime, declarations, original README, and component APIs match. Existing static and
bundled variants have identical indexes, full contracts, extracted type files, and metadata.
Only the usage-page bodies differ. Eight shared components have concise manually reviewed
behavior and minimal examples; others retain canonical usage/accessibility facts. All 85 pages
include exact prop dependencies and a full-contract fallback. Facts come from canonical contracts,
declarations, and runtime. Compile the eight minimal examples and validate every page's props
and fallback before authoring. Freeze protocol, generator, tasks, checker, prompts, and packages.

Run independent trusted interactions through T3's collaborative browser at 390px and 1280px.
The overlay reuses the earlier checker. The brief now explicitly requires control-to-control
Tab wrapping, resolving the earlier native/browser-chrome ambiguity. The form checks all custom
errors and their associations, required terms, trimmed live saved status, keyboard checkbox,
and complete reset. The directory checks accessible tabs/panels, automatic keyboard activation,
filtering, name sort and accessible direction, row actions, empty state, clear/Escape, persistent
application state, and bounded outer width. No subjective style scoring.

Freeze assertion meanings. A tooling/locator/timing defect may be corrected for evaluation,
with initial results retained and the correction applied consistently. Never alter acceptance
to favor an app. App failures receive one objective repair message without documentation hints.
Capture initial source, counters, and checks before repairs; include all repair costs.

Report per-task, per-attempt, and combined provider input/output/cache counters, total tokens,
uncached input plus output, app/CSS reference tokens, tool requests, active time, and behavior
success. Total includes cached input; output already includes reasoning. Do not double count or
claim prices. Setup, coordinator analysis, and independent evaluation are outside author totals.
Measure actual reads/lookup output from scoped traces, never infer uptake from a file listing.
Report component choices, full-contract and implementation reads, failed reads, and repeated reads.
Compare both attempts and task totals. Small repeated samples give descriptive evidence, not a
general adoption probability or causal cost estimate. Quality equivalence comes before cost.

Preserve earlier evidence. New sanitized traces, hashes, sources, prompts, timelines, initial
and repaired evaluations, and computed summaries go under
`.work/agent-guidance-cost/bundled-evidence/`. Publish a research report and an interactive
comparison for review, with limitations and the concrete prototype changes to consider.
