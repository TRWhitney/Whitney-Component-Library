# Metadata experiment protocol

This is a historical study design, not an instruction to run another experiment. Results are
in the [study report](agent-guidance-metadata.md).

## Design

Six fresh directory attempts, three each with integrated guidance and full metadata or
identical packages omitting only scripts/devDependencies. Alternate full/trimmed, trimmed/full,
full/trimmed. Retain four exports and all guidance/runtime/declarations. No native condition;
older results remain context.

## Boundaries and checks

Use neutral assignments/names and fresh gpt-6.1-sol/high contexts without parent history.
Authors inspect app/dependencies, edit app/CSS and run matching builds, with no browser
self-checks. Clean-install actual archives before freezing; verify only metadata fields differ,
links/props/examples/types and consumer builds. Freeze package/assignment/checker sources.

## Measures and decision

Independent directory checks run 48 assertions per app across 390px/1280px, 288 primary
assertions. Narrow click recovery requires a separate DOM read confirming the exact postcondition.
Retain app failures and targeted repair costs separately from partial tooling runs. Measure
whole metadata/index/declarations, returned usage/runtime/CSS and every repetition. Stop after
six attempts; require no quality regression before considering savings. A small single-task
pilot cannot establish general improvement or savings over React/CSS.

Provider total counts input plus output, including cached input and reasoning once. Uncached
input plus output is a diagnostic, not a price. Reference/source estimates are separate from
provider accounting and cannot be subtracted to attribute savings. Include author reads,
failures, checks and repairs; exclude coordinator preparation, evaluation and analysis.
Inherited instruction costs remain in author totals. Study inputs were frozen before
authoring; raw captures are no longer retained.

Raw captures and one-off study tooling were removed. Exact historical replay is unavailable.
See the [evidence retention policy](agent-evidence-retention.md).
