# Explicit wording experiment protocol

This is a historical study design, not an instruction to run another experiment. Results are
in the [study report](agent-guidance-wording.md).

## Design

Six fresh directory attempts, three each with current guidance and explicit Tabs defaults
plus controlled SearchField clearing. Alternate current/explicit, explicit/current, current/explicit.
Only those two usage pages differ. Retain props/full references, metadata, runtime/CSS, pointers
and exports. Combined page growth must be at most 80 o200k_base tokens and 10%.

## Boundaries and checks

Tabs preserves state/containment while naming horizontal/automatic defaults and first-enabled
fallback. SearchField shows value/onChange/onClear with parent useState. Clean-install both
archives and verify parity, 85 props closures, nine examples and types/builds before freezing.
Neutral fresh gpt-6.1-sol/high authors edit app/CSS and run builds. Do not direct authors to
avoid runtime; all allowed reading routes remain in results.

## Measures and decision

Use 48 independent assertions per app across 390px/1280px, 288 primary assertions. Separate
partial tool failures; accept a failed click only with verified exact postcondition. Include
all author failures and repair costs. Final results may reuse passing initial checks without
claiming another execution. Compare every pair, runtime/read ordering, complete costs and
correctness. Stop after six authors. Fewer runtime readers alone cannot establish improvement;
no native comparison or automatic adoption follows.

Provider total counts input plus output, including cached input and reasoning once. Uncached
input plus output is a diagnostic, not a price. Reference/source estimates are separate from
provider accounting and cannot be subtracted to attribute savings. Include author reads,
failures, checks and repairs; exclude coordinator preparation, evaluation and analysis.
Inherited instruction costs remain in author totals. Study inputs were frozen before
authoring; raw captures are no longer retained.

Raw captures and one-off study tooling were removed. Exact historical replay is unavailable.
See the [evidence retention policy](agent-evidence-retention.md).
