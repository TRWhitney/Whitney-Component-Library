# Wording experiment protocol

Whitney authorized testing the runtime investigation's recommendation with "Please test".
Compare current guidance with explicit Tabs defaults and controlled SearchField clearing in
six fresh directory author attempts, three per condition. Freeze this protocol before authors.
Completed research may be committed under the standing instruction; production adoption remains
for review. No new runtime/API, metadata, exports, README/AGENTS, or canonical contract changes.

Only dist/usage/tabs.md and dist/usage/search-field.md may differ. Retain exact inline props,
full contracts, all other guidance, metadata, runtime/CSS, declaration pointers, and entry points.
Tabs keeps activation/selection, parent-owned state, and containment advice while explicitly
stating horizontal/automatic defaults and first-enabled fallback. SearchField replaces its
uncontrolled example with value/onChange/onClear and names the parent useState setup.
Combined growth of the two complete pages must be at most 80 o200k_base reference tokens and
10% of their control size. Preserve a diff and page hashes before launch.

Use the preceding people-directory brief and scaffold, changing only each disposable path.
Names case_20261010b_01 through case_20261010b_06 and actual assignments have no condition or guidance hints.
Alternate current/explicit, explicit/current, current/explicit across the repetitions. Use fresh
gpt-6.1-sol/high contexts with no parent-history fork. Authors inspect only their app/dependencies;
only src/app.tsx/styles.css are writable. No network, Git mutations, other fixtures/repositories,
delegation, check changes, added tests, or browser self-checks. Reading routes remain unrestricted
within that scope, with no directive to avoid runtime. Inherited instructions remain in totals.

Preflight both actual archives by clean install. Verify only the two usage bodies differ, runtime
and props parity, guidance links, all 85 props closures and nine examples, consumer types/builds,
and installed tree hashes. Verification supplies useState/query/setQuery for the SearchField
fragment in both conditions; that support is confined to preflight, outside author packages.
Record packages, assignments, prompts, source/protocol/evaluator hashes, sizes, model and effort.

Reuse the frozen 48-assertion directory checker at 390px/1280px, 288 primary assertions.
Use the T3 browser and previous transport adapter. Retain tool failures separately. Narrow click
recovery accepts a failure only when a separate DOM read confirms the exact requested postcondition.
Never change assertions or authored source during evaluation. Capture initial source, trace,
provider counters and build results first. Repair failed app assertions only in the same author
context, retain initial failures, and include all repair costs. If unchanged apps require no
repairs, record initial results as final without claiming a second browser execution.

Measure completed input plus output, uncached input plus output, correctness, runtime/CSS reads,
usage uptake, reference/read ordering, whole metadata/index/root reads, failed reads/builds,
tool requests/output, source size, and active author time. A smaller runtime-read count alone is
insufficient. Inspect each matched repetition and retain unfavorable results. Stop after six
completed authors and independent checks; no extra runs to improve a result.

Cached input is a subset of input; reasoning is a subset of output. Uncached input plus output is
a diagnostic, not a price. Reference estimates use o200k_base and cannot be subtracted from
provider totals to attribute savings. Coordinator preparation/evaluation/analysis is excluded.
Retained traces omit system/developer content and opaque reasoning. This single-task pilot cannot
establish general savings or improvement over native React/CSS; no fresh native condition is run.
