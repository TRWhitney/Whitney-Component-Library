# Concise guidance experiment protocol

This is a historical study design, not an instruction to run another experiment. Results are
in the [study report](agent-guidance-concise.md).

## Design

Eighteen fresh attempts: dialog, form and directory, two repetitions each under current,
concise and React/CSS. Current is baseline 1f35651. Concise changes usage prose for eight
components while preserving exact props, examples, full links, metadata, runtime and exports.
Tabs may retain verified default/fallback facts. Prose words must fall at least 20% overall;
whole-page tokens must fall overall and for every task.

## Boundaries and checks

Balanced block order is current/concise/native, concise/native/current, native/current/concise,
native/concise/current, current/native/concise, concise/current/native. Use fresh gpt-6.1-sol/high
contexts, neutral path-only assignments and no guidance/runtime-avoidance hints. Authors edit
app/CSS and run matching builds; no self-check browser/tests or other-fixture access. Preflight
actual archives, eight-page-only difference, unchanged props/examples, 85 closures, nine examples
and consumer types/builds, then freeze before launch.

## Measures and decision

Independent checks use 48 assertions per overlay/directory and 40 per form across 390px/1280px,
816 primary assertions. Retain initial failures, same-author targeted repairs and all costs.
Separate partial transport runs; exact-postcondition DOM verification permits narrow recovery.
Size/correctness must pass and completed total must be lower in aggregate and each task sum
for a descriptive cost-success result. Report all six matched pairs and native/uncached results.
A favorable aggregate with a worse task sum is mixed. Stop after 18 authors; adoption is separate.

Provider total counts input plus output, including cached input and reasoning once. Uncached
input plus output is a diagnostic, not a price. Reference/source estimates are separate from
provider accounting and cannot be subtracted to attribute savings. Include author reads,
failures, checks and repairs; exclude coordinator preparation, evaluation and analysis.
Inherited instruction costs remain in author totals. Study inputs were frozen before
authoring; raw captures are no longer retained.

Raw captures and one-off study tooling were removed. Exact historical replay is unavailable.
See the [evidence retention policy](agent-evidence-retention.md).
