# Concise guidance comparison protocol

Whitney authorized the 18-attempt comparison and clarified that clearer wording should require
fewer words. This pass tests a genuinely shorter wording-only prototype. Production adoption is
excluded. Freeze packages, prompts, assignments, source hashes and this protocol before launch.

## Conditions and boundaries

Current is the built package at baseline 1f35651. Concise changes only usage prose for
AppearanceProvider, Button, Checkbox, Dialog, SearchField, Table, Tabs and TextField. Preserve
existing facts, labels/events/validation/state/containment advice, exact inline and standalone
props, examples, full contracts, other usage pages, discovery/index, metadata, runtime/CSS, README
and exports. Tabs may retain the previously verified default/fallback facts in shorter wording.
No new reading-route or retrieval instruction. Whole-page reference tokens must fall overall
and for every task; prose words must fall overall by at least 20%. Do not claim complete-page
savings equal prose-only savings. Retain the exact package diff and per-page measurements.
Native receives the same React/TypeScript scaffold and requirements, without the library package.

## Tasks and order

Reuse bundled-tasks.json unchanged: profile modal editor, validated contact form and people
directory. Each task has two repetitions per condition, six authors per condition, 18 total.
Balanced order: overlay1 current/concise/native; form1 concise/native/current; directory1
native/current/concise; overlay2 native/concise/current; form2 current/native/concise; directory2
concise/current/native. Launch in this frozen order with at most three authors active.
Use fresh gpt-6.1-sol/high contexts, no parent history, neutral names case_20261010c_01 through18
and assignments that only identify the neutral prompt path. Library briefs ask only for appropriate
installed components; no hints about candidate, guides, types, runtime or condition. Native briefs
ask for React/CSS without a component library. Scope allows only the app and installed dependencies,
editing only src/app.tsx/styles.css. No network, Git mutations, other repositories/fixtures,
delegation, scaffold/check changes, added tests or browser self-checks. Inherited instructions remain
in measured counters. No additional initial authors after the 18 frozen attempts.

differ, unchanged exact props/examples/references, all 85 props closures, nine examples, guidance

Retain transport failures and partial assertion rows; replay unchanged checks after inspecting the

Capture every completed initial author before evaluation. If app assertions fail, ask the same
author to correct only observed defects; retain initial failures and all repair counters. Never edit
assertions or app source as evaluator. Failed setup/tool operations remain documented. Final ledgers
may reuse passing initial results when no repair occurred, without claiming another execution.

## Measures and decision

Measure prose whitespace-delimited words after removing fenced code; complete-page o200k_base
reference tokens; provider input, cached input, output and reasoning counters; total input/output
and uncached input/output; initial/final correctness; failed builds/reads; repairs; source size,
outer requests/tool-output estimates, active author time and returned reading content/order.
Cached input is a subset of input, reasoning a subset of output. Uncached input/output is diagnostic,
not a price. Reference estimates cannot be subtracted from provider counters to attribute savings.
Coordinator preparation/evaluation/analysis/review is excluded. Do not retain private system/developer
content or opaque reasoning; session metadata and sanitized public traces suffice.

Report aggregates, task sums and all six matched repetitions, including unfavorable results.
For a descriptive cost-success result, candidate guidance must meet the source-size criteria,
finish at least as many apps correctly as controls with no unresolved regression, and use less
completed total input/output than current in aggregate and in each of the three task sums.
Also report candidate/native comparisons and uncached input/output separately. A favorable total
aggregate with worse task sums, smaller prose without completed savings, or lower uncached cost
alone is a mixed result. No production adoption follows automatically. Two repetitions/task,
one model/effort and reused tasks cannot establish general or causal savings.
