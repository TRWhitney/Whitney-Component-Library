# Component Library Context

This project provides reusable React components, styles, behaviors, and higher-level constructs
for consistent application development by people and agents.

## Language

**Component contract**:
The canonical, structured description of a public export's intended and inappropriate uses,
alternatives, content rules, composition, states, accessibility obligations, and focused examples.
Human and machine-readable guidance derive from this source.

**Breadth-aware vertical slice**:
A first-release strategy that implements one complete class of use case while validating shared
foundations against the wider component families the library is expected to support later.
_Avoid_: treating the initial workflow as the boundary of the eventual component system.
