# 05 Choice Controls

**What to build:** Checkbox, checkbox group, radio group, switch, and segmented control exports with
typed single, multiple, binary, and bounded-exclusive choice semantics.

**Blocked by:** [Field and Text Entry Family](04-field-and-text-entry-family.md)

**Status:** blocked

- [ ] Each control advertises when its choice model is appropriate and names preferred alternatives.
- [ ] Native form participation, labels, descriptions, validation, reset, and submitted values are
      deterministic.
- [ ] Group keyboard behavior follows the relevant selection pattern without conflating focus and
      selection.
- [ ] Segmented selection uses accent text and a gliding bottom rail with no persistent selected
      fill or elevation.
- [ ] Hover on an adjacent segment cannot cover the selected segment's rail.
- [ ] Equivalent adjacent choices maintain consistent size and alignment.
- [ ] Indeterminate checkbox, read-only where meaningful, disabled, invalid, and required states
      are covered.
- [ ] Pointer, touch, keyboard, screen-reader, theme, reduced-motion, SSR, hydration, and type
      checks pass.
