Extend this existing React and TypeScript board application with a piece inspector. Preserve its board layout, styling, arrow-key navigation, adjacent-empty-square movement rules, and existing game controls. Use installed dependencies where suitable; do not add dependencies. Native elements are allowed. Work only inside this app and its installed dependencies.

Activating an occupied square by pointer, Enter, or Space must select that piece and open a modal inspector named with its current label. It contains a required field named "Piece name". "Save" commits a nonempty trimmed label; "Cancel", "Close inspector", and Escape discard unsaved edits. Dismissal returns keyboard focus to that piece's square. Do not apply edits until Save.

The inspector also offers "Move to next empty square" and "Remove piece". Moving relocates only that piece to the first empty square after its current index, wrapping after square 16, closes the inspector without committing draft edits, and focuses its destination square. Removing deletes only that piece, closes without committing draft edits, and focuses "Reset board". Keep the other piece unchanged. Reset board restores the initial pieces and selection. Focus must stay inside the inspector while open. Keep the app usable at 390px and 1280px. Do not introduce unrelated UI or rewrite the application into a template.

Run the provided type/build check and verify the interactions in a browser. The dev command uses a dedicated fixed port in package.json; use that port without changing it. Briefly report completion and any known limitations.
