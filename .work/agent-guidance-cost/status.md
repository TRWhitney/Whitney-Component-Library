# Agent guidance cost

## Outcome

The integration and bounded research are complete. The compact index fell from 4,867 to 1,584
reference tokens, 67.5% smaller. Production emits 85 bundled usage pages, complete canonical
references, 85 standalone props files and nine declaration pointers. Runtime, canonical contracts,
human documentation, manifest and four public entry points remain intact. Fingerprints reject
stale summaries and eight shortened behavior pages.

The [layout study](../../docs/research/agent-guidance-layout.md) measured 29.6% lower completed total
than bundled control on the directory task, still 1.92 times native React/CSS. The
[metadata study](../../docs/research/agent-guidance-metadata.md) reduced metadata reference tokens
62.0%, but used 7.0% more completed total tokens and 13.2% more uncached input plus output. All
six authors read metadata and runtime; paired results varied. Production metadata was unchanged.

The [runtime investigation](../../docs/research/agent-guidance-runtime-reads.md) found all six
runtime reads before implementation. Four followed guidance, one preceded it, and one requested
both together. Visible commentary did not establish why. The 11,525 returned runtime-body reference
tokens were an estimate, not provider savings. Clearer examples/defaults were recommended for testing.

## Historical validation

The [integration proposal](../../docs/research/agent-guidance-proposal.md) records passing repository
checks, 1,205 tests across 86 files, TypeScript 5/6/7 and chart/editor isolation. Clean-package
verification covered props/examples, SSR, hydration, types and browser builds with React 18.3.1
and 19.2.8. The integration audit compared 201 runtime files, 195 declarations, 255 guidance files
and nine source-map shifts. [Independent review](review.md) passed both axes with no findings.

Metadata preflight covered both clean-installed archives, 85 props closures and nine examples.
All 1,044 nonmetadata files matched, with only scripts/devDependencies differing. Six author builds
and 288 unique browser assertions passed without app repairs. A Summary-tab tool click failed;
a separate DOM check verified the exact postcondition. The analyzer's prompt-hint check was narrowed
and the report disclosed the correction. Independent correction review found no remaining findings.

These are recorded checks from the completed work, not new validation. Raw captures, trace/hash
inventories and obsolete replay tooling were removed under the
[retention policy](../../docs/research/agent-evidence-retention.md). The reports and production
checks remain; the old studies cannot be independently replayed from the retained tree.
