# Test explicit component guidance

## Problem Statement

Six prior authors read runtime before coding despite guidance covering most required behavior.
The traces do not establish why. Whitney authorized testing the concrete wording recommendation.

## Solution

Run six fresh directory attempts comparing current usage with explicit Tabs defaults and a
controlled SearchField example. Present measured cost, reading routes, correctness, and limits.

## User Stories

1. As Whitney, I want measured results before adopting wording as a token-cost improvement.
2. As a consuming agent, I want usable guidance and exact props without an imposed reading route.

## Implementation Decisions

Use the [frozen protocol](../../docs/research/agent-guidance-wording-protocol.md). Change only two
usage pages in disposable packages. Keep production guidance, metadata, runtime/types and public
interfaces unchanged. No instruction to avoid runtime. Retain all six attempts and repair costs.

## Testing Decisions

Clean-install both archives and validate parity, size budget, guidance/props/examples and builds.
Reuse the independent 48-assertion browser checker. Audit provider counters and content returned
by tools. Review results independently before committing the completed experimental outcome.

## Out of Scope

Production adoption, new public APIs, README/AGENTS changes, publishing/pushing, extra trials,
and claims of general savings or superiority to native React/CSS.

## Further Notes

Whitney authorized this experiment with "Please test" and previously authorized liberal commits
of completed outcomes. The [runtime investigation](../../docs/research/agent-guidance-runtime-reads.md)
is the accepted source for this bounded comparison.
